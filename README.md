# TLOZ.net — publish-ready fan site

Upload every file in this folder to the root of your GitHub Pages repository.

## Included
- `index.html` — complete fan site with 21-game launch timeline and story guide
- `404.html` — branded fallback page
- `CNAME` — sets the custom domain to `tloz.net`
- `robots.txt` and `sitemap.xml` — basic search-engine setup
- `.nojekyll` — serves the static files directly on GitHub Pages

## Publish
1. Upload all files to the repository root and commit them to `main`.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Confirm the custom domain is `tloz.net`.
5. Configure TLOZ.net DNS using GitHub Pages' current custom-domain instructions.
6. After DNS verifies, enable **Enforce HTTPS**.

## Content scope
The story guide covers 21 core original adventures from 1986 through 2024. Remakes, remasters, ports, and spin-offs are intentionally excluded.

The page does not bundle Nintendo artwork, music, screenshots, or official logos. Story descriptions are original fan-written summaries.
